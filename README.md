# 三板斧期市观察

**把盘面变化、规则判断和风险测算写进一份能追溯的日报。**

Three-Axes Futures 面向期货仿真研究：在预设的 51 个品种中识别月、周、日均线状态，计算 ATR 参考止损距离与假设账户下的仓位上限，并生成适合阅读、保存和复核的中文长报告。项目不自动交易。

报告回答四个问题：今天的数据是否完整？哪些变化值得关注？筛选结果由哪些条件产生？如果条件改变，原先的解释应如何调整？

## 先看一份报告

[新版长报告](examples/reports/review_preview_2026-09-16.md) 展示新版本的写作与证据结构，样例的实际生成方式和验证程度见 [样例说明](examples/README.md)。

原有 XML 和榜单保留用于审阅历史版本。它们存在已知口径问题，不作为新版本正确性的标准答案。

## 报告怎样建立可信度

| 层次 | 报告提供什么 | 能支持的结论 |
|---|---|---|
| 输入事实 | 来源、数据日期、有效覆盖数、缺失项及输入留档 | 本次计算实际使用了什么 |
| 规则结果 | 月/周/日 MA10 证据、ATR、仓位约束和逐项计算 | 给定输入下，规则是否触发 |
| 条件分析 | 板块分布、短期变化与趋势状态的差异、后续观察条件 | 哪些解释与现有证据相容，哪些仍需确认 |

结构和数值检查通过，不代表源站价格已被独立证实；共振成立，不代表下一交易日会沿该方向运行。报告明确标注证据边界，不把计算结果写成预测承诺。

## 本地运行

使用 Python 3.10 或更新版本，建议先建立虚拟环境：

```bash
python -m pip install -r requirements.txt
python daily_report.py --date 2026-09-16
```

Windows 若默认编码不是 UTF-8，可使用 `python -X utf8` 运行安装及脚本。

`--date` 是要分析的交易日。省略时取上海自然日期；程序不猜测节假日前一个交易日。没有该日行情的品种会被排除并记录原因。历史数据来自当前源站返回值，不能冒充当时留存的行情版本。

默认生成 Markdown、飞书 XML、结构化结果、快照和原始输入档案。可用 `--output-dir` 或 `FUTURES_HOME` 指定输出目录。纯本地运行不需要飞书或 PandaAI；只有 `--account` 才会查询当前持仓，且不将其回填到历史交易日。

```bash
# 离线复算已留存的原始输入；manifest 路径取自上次输出
python daily_report.py --replay raw/<run_id>/manifest.json

# 旧快照写作预览：不补造缺失的均线、持仓变化和合约规则
python daily_report.py --legacy-snapshot examples/snapshots/regime_2026-09-16.csv

# 同口径简版筛选
python screen_three_axes.py --date 2026-09-16

# 黄金账户监控，需要 PandaAI CLI 和明确的权益字段
python monitor_gold.py

# 离线回归测试，不访问行情或账户
python -m unittest discover -s tests -v
```

## 三板斧在这里的含义

**选环境。** 月线收盘高于月 MA10，周、日收盘均高于各自 MA10 且周、日均线上升，记为多头共振；相反为空头共振。其他有效样本记为不共振，历史不足记为无法判断。当前未结束的周、月也参与计算，状态可能变化。

**计算参考止损。** 用前收盘价构造真实波幅，取最近 14 根 TR 的简单均值，再乘以 1.5。主力连续价格用于研究，不能直接当作实际合约的委托价格。

**估算仓位。** 默认假设权益 500 万元、风险预算 1%、单品种名义敞口上限 10%，两项手数取小。缺少乘数不出手数；受限原因分别展示。各候选的手数不能相加当作组合建议。

这些是研究参数，不是最优参数的证明。详见 [方法论](docs/METHODOLOGY.md)。

## 当前能力

已实现：行情结构检查、同日样本统计、信号证据、风险测算、长报告与简报、输入归档和离线复算。报告将数据问题作为正文的一部分，不把查询失败默认为零。

[飞书部署说明](docs/PIPELINE.md) 提供可选发布步骤。仓库不包含自动调度、完整发布事务或跨平台去重服务，配置示例不会自动安装定时任务。

尚未实现：独立第二来源行情核验、交易所日历自动判断、主力换月映射、组合仓位分配、策略收益验证。因此不生成“成功概率”“已验证盈利”等结论。
