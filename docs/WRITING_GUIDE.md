# 日报写作标准：信息充分，判断有据

读者收藏一份报告，是因为它帮助理解问题，并能在以后复用。一段解释要么增加证据，要么说明机制，要么交代观察条件；不能只换一种说法重复结论。

## 阅读顺序

摘要先说明研究日期、有效样本和主要结构。随后解释上涨家数与趋势共振为什么可能不同，再展开板块、状态变化、价格与持仓。候选明细提供计算依据，风险章节解释限制，末尾保留异常与复核入口。

摘要用于快速阅读；正文用于理解；附表用于核查。三层可以共享数字，不应整段重复。

## 每个判断必须有落点

事实写“在本次有效样本中，上涨占比为……”，不含糊写“市场全面走强”。规则写“满足本项目的多头共振条件”，不写“趋势已经确立”。推断写清条件，例如“若后续周线仍高于MA10，且均线方向条件保持，当前同向状态才得以维持”。

不要把“待确认”塞进每句话。先交代数据范围，对确定的计算结果直接表述；只有跨越证据层级时补充条件。

## 值得展开的内容

- 横截面与时间序列：今日多数上涨，不必然改变多周期均线。展示两个分母，不替市场编造原因。
- 板块差异：覆盖数、涨跌数、等权平均、共振分布一起读。少量品种不能代表完整产业链。
- 状态变化：从不共振进入多头、从空头直接进入多头、退出空头，分别描述。
- 规则距离：收盘与MA10的距离用于复核位置，不是成功率。
- 仓位限制：预算、每手风险、每手名义价值、两项手数及限制来源。
- 后续观察：需要再次看到什么，什么变化会使原判断失效。

## 不使用的表达

“资金抢筹”“主力出逃”“空头主动打压”需要交易行为证据。“趋势信号最强”“大概率上涨”“胜率更高”需要比较对象、样本与检验。“把风险锁死”与滑点、跳空的事实不符。

改写为“价格上涨、总持仓增加”“当前满足五项筛选条件”“在假设止损价格成交时的测算损失”。保留分析，不把解释写成观察事实。

## 长度的取舍

完整数据通过板块分析、候选证据和风险算例自然形成长报告。数据不足时缩短市场判断，把篇幅用于说明影响与可复核部分；不使用合成行情充当正式样例。

免责声明保留一处，不变的教学内容尽量放方法论。即使没有变化，也如实写“未观察到规则切换”，不制造故事。长报告应有信息密度，不以字数代替质量。
