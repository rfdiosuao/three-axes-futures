# 样例的证据等级

原有 `snapshots/regime_2026-09-16.csv`、`three_axes_*.md`、`daily_report_2026-09-16.xml` 和元数据是旧版本产物，未附完整输入日线与规则响应。它们不作为新版本正确性的标准答案。

旧XML混入次日黄金报价；旧榜单将部分敞口受限解释为风险受限。这些文件保留用于历史审阅。

新版长报告及其来源核验结果见 `reports/review_preview_2026-09-16.md` 和 [验证记录](../docs/VALIDATION.md)。原始档案保存在本地raw目录，不将“单一来源复算一致”表述为“行情已独立认证”。

本次新版长报告使用2026-09-17重新获取的完整输入生成，不是旧CSV的文字扩写。同名XML与 `.meta.json` 一并提供；51个品种的收盘价、两位精度ATR和共振分类与旧快照一致，涨跌口径差异见验证记录。

`--legacy-snapshot` 仅依据旧CSV预览写作，不反推缺失的均线证据、持仓变化、状态环比或当日规则。完整日线模式与旧快照模式在报告开头明确区别。
